PRANIC HEALING WEBSITE
======================
Original healer-focused website inspired ONLY by the visual direction and information architecture of Global Pranic Healing.

PALETTE
-------
The visual palette is strictly restricted to:
- White (#ffffff) — dominant background
- Gold (#d8a52b, plus #e3bf68 light / #a9791d dark tints of the same gold hue) — the only accent color
- Black / gray (#1a1a1a, #242424, #eeeeee, #f7f7f7, #dddddd, #bbbbbb, #aaaaaa, #999999) — text, borders and minimal UI only
No cream, beige, brown, orange, blue, green, or purple appears anywhere in the stylesheet.
All imagery (hero orbs, portrait placeholder, blog thumbnails) is built from flat CSS shapes/gradients using only white, gold and black/gray — no photographic or off-palette backgrounds.

Files:
- index.html
- styles.css
- script.js

Open index.html in a browser.

Before launch:
1. Replace placeholder healer portrait and contact details.
2. Connect the enquiry form to your email/CRM.
3. Replace sample event/blog dates and copy with real content.
4. Add the healer's approved photographs.
5. Review all health-related claims and add any required local disclaimers.

The visual system intentionally avoids copying proprietary Global Pranic Healing images, logos, or exact page copy.
