# Replit setup

This project is a static HTML/CSS/JavaScript website. No package installation or
backend service is required.

## Run

The `Start application` workflow serves the project directory with Python's
built-in HTTP server on port 5000:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

Open the Replit Preview to view the site. The enquiry form is currently a
front-end placeholder and should be connected to an email or CRM before launch.
